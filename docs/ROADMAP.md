# 로드맵

상태: ⬜ 대기 · 🔄 진행 · ✅ 완료 · ⏸ 보류

## 공통 완료 조건 (DoD)
1. `uv run pytest` 전부 통과 (실행 결과 첨부)
2. 해당 기능의 합성 케이스 비교 시트(입력 | 출력 | 차이) 생성
3. 비생성 검사·원본 불변 검사 통과
4. ROADMAP 상태 갱신 + DECISIONS에 새 결정 기록 + 미해결 문제 보고 + 커밋 메시지 제안
5. 위 중 하나라도 확인하지 못했으면 "완료"가 아니라 "부분 완료"로 보고

## M0 기록 (2026-11-01)
- 의존성: `pillow`, `numpy`, `pytest`(dev)
- 검증됨 (macOS): pytest 38개 통과, 합성 케이스 15개 항등 출력 픽셀 단위 동일·비생성 위반 0, 비교 시트 확인
- 검증됨 (실제 러프 `rough_sketch.png`, 900×1100 RGBA 8-bit): 항등 출력 픽셀 단위 동일, 입력 해시 불변, 비생성 위반 0, `samples/input/` 쓰기 거부 확인
- 미검증: Windows PowerShell 실행
- M1 참고 (실제 러프 관찰): 완전 불투명 픽셀 없음(알파 최대 203, 중앙값 51) · 선 굵기 약 2~3px에 연필 질감으로 가장자리가 들쭉날쭉함 · 옅은 보조선(얼굴 십자선) 있음 · 틈을 두고 덧그은 윤곽(머리 양옆·얼굴 윤곽)과 X 교차(목–어깨)가 실제로 존재
- 해결: 16-bit RGB(A) PNG를 Pillow가 경고 없이 8-bit로 줄이던 문제 → PNG 헤더의 비트 깊이를 먼저 읽어 거부
- 미해결: 비생성 허용치 d가 고정값(D-7)
