# 로드맵

상태: ⬜ 대기 · 🔄 진행 · ✅ 완료 · ⏸ 보류

## 공통 완료 조건 (DoD)
1. `uv run pytest` 전부 통과 (실행 결과 첨부)
2. 해당 기능의 합성 케이스 비교 시트(입력 | 출력 | 차이) 생성
3. 비생성 검사·원본 불변 검사 통과
4. ROADMAP 상태 갱신 + DECISIONS에 새 결정 기록 + 미해결 문제 보고 + 커밋 메시지 제안
5. 위 중 하나라도 확인하지 못했으면 "완료"가 아니라 "부분 완료"로 보고

## 마일스톤
| # | 이름 | 상태 | 범위 | 완료 조건 |
|---|---|---|---|---|
| M0 | 입출력·안전장치·비교 하네스 | ⬜ | RGBA I/O, 원본 보호, 항등 CLI, 비교 시트, 합성 이미지 생성기 | 항등 출력이 입력과 픽셀 단위 동일, 차이 0, 해시 보존 테스트 통과 |
| M1 | 선 그래프 추출 실험 | ⬜ | 마스크화, 세선화·중심축 비교, 끝점/분기점 추출, 오버레이 시각화 | 합성 케이스별 실패 양상 보고서, DECISIONS에 추출 방식 결정 기록 |
| M2 | 덧그은 선 병합 (F-A) | ⬜ | M1 결정에 따름 | 덧그림 케이스 병합 & 별개 평행선 미병합, 이탈 ≤ 허용치 |
| M3 | 교차·분기 보존 (F-C) | ⬜ | | X/T/Y 위상 유지 테스트 |
| M4 | 떨림 완화 (F-B) | ⬜ | | 모서리 유지 + 이탈 ≤ 허용치 |
| M5 | 렌더링·굵기/가장자리 (F-D) | ⬜ | | 원본 굵기 프로파일 재현 오차 기준 |
| M6 | 실제 러프 검증·파라미터 정리 | ⬜ | | 사용자 시각 승인 |

M2 이후 범위·순서는 M1 결과에 따라 제안 후 승인으로 확정한다.
