# 요구사항

## 목적
러프의 선을 정리하되, 새 요소를 만들지 않고 원본과 최대한 일치하는 선화를 만든다.
ChatGPT·Claude 등 대규모 생성형 모델에 그림을 맡기는 방식은 사용하지 않는다(원본 재해석 위험).

## 입력
- PNG, RGBA(기본). 투명 배경. 잉크 정보는 주로 알파 채널에 있다.
- RGB/그레이스케일 입력은 알파로 변환하는 규칙을 정해 지원한다(M0에서 결정).
- 덧그은 선, 미세한 떨림, 교차·겹침이 포함될 수 있다.
- 획 순서·필압 정보는 없다(래스터만 주어짐).

## 출력
- RGBA PNG, 입력과 동일한 캔버스 크기·종횡비. 투명도 유지.
- 원본을 덮어쓰지 않는 별도 파일.
- 비교 시트 PNG(입력 | 출력 | 차이) 동시 생성 옵션.

## 기능 요구사항
| ID | 내용 | 비고 |
|---|---|---|
| F-A | 같은 윤곽을 덧그은 선을 하나의 대표 선으로 병합 | 의미가 다른 선(예: 얼굴 윤곽과 머리카락)은 병합 금지, 애매하면 유지 |
| F-B | 미세한 떨림 완화 | 의도된 모서리·곡률·작화 스타일 유지 |
| F-C | 교차(X), 접합(T), 분기(Y), 끝점, 짧은 선–긴 선 연결 관계 유지 | 거의 평행한 겹침 포함 |
| F-D | (선택) 굵기·농도·가장자리 정리 | 원본 굵기 변화·안티앨리어싱을 획일화하지 않음. A~C와 분리 |
| F-IO | 원본 보호: 입력 파일 불변, 입력 폴더에 쓰지 않음, 기존 파일 덮어쓰지 않음 | |
| F-VIS | 각 처리 단계 결과를 원본과 시각 비교 가능 | |

## 충실도 기준 (측정 가능)
- 비생성: 출력 알파>0 픽셀은 원본 잉크 마스크를 허용치 d만큼 팽창한 영역 안에 있어야 한다.
  d 기본값: 국소 선 굵기의 절반, 최대 2px (잠정, DECISIONS에서 확정).
- 형태: 정리된 중심선과 원본 중심의 최대 이탈(Hausdorff) ≤ 허용치(기본값은 M1 이후 DECISIONS에서 확정).
- 각 처리 기능은 개별로 켜고 끌 수 있어야 한다.

## 비기능 요구사항
- 로컬 실행, 네트워크·대형 AI 모델 불필요.
- Windows 우선(문서의 명령은 PowerShell 기준), 경로 처리는 OS 독립(`pathlib`).
- Python + uv(`uv add`, `uv run`). pip 직접 사용 금지.
- 의존성 최소화: Pillow, numpy 기본. 그 외(OpenCV, scikit-image 등)는 사용자 승인 후.
- 사용자가 읽고 유지보수할 수 있는 단순한 구조.
- 성능 목표(잠정): 2000×2000 이미지 1장 1분 이내.

## 범위 밖
